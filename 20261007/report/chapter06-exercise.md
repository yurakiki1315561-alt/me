# 6장 자바스크립트 언어 — 이론문제

---

## 1. 자바스크립트의 특징이 아닌 것은?

**정답: ① 자바스크립트 프로그램은 컴파일 과정이 간단하다.**

### 설명

- **① 자바스크립트 프로그램은 컴파일 과정이 간단하다**: 개발자가 별도로 컴파일하여 실행하는 언어가 아니므로, 교재에서 설명하는 특징이 아니다.
- **② 자바스크립트 프로그램은 HTML 페이지에 소스 코드 형태로 삽입된다**: `<script>` 태그 안에 작성할 수 있다.
- **③ Netscape사가 처음 개발하였다**: 자바스크립트는 Netscape에서 처음 개발되었다.
- **④ 웹 페이지에 동적인 변화를 만드는 데 사용된다**: 사용자 입력에 반응하거나 웹 페이지의 내용을 바꿀 수 있다.

## 2. 자바스크립트 언어로 할 수 없는 것은?

**정답: ③ 로컬 컴퓨터의 파일을 삭제할 수 있다.**

### 설명

- **① 사용자로부터 마우스나 키 입력을 처리할 수 있다**: 클릭이나 키보드 입력을 처리할 수 있다.
- **② 새 브라우저 윈도우를 생성할 수 있다**: `window.open()`으로 새 창을 열 수 있다. 다만 브라우저가 팝업을 차단할 수 있다.
- **③ 로컬 컴퓨터의 파일을 삭제할 수 있다**: 일반적인 웹 페이지의 자바스크립트는 보안상의 이유로 사용자 컴퓨터의 파일을 마음대로 삭제할 수 없다.
- **④ CSS3 프로퍼티 값을 변경하여 HTML 태그의 모양을 동적으로 바꿀 수 있다**: 글자색, 배경색, 크기 등을 변경할 수 있다.

## 3. 다음 중 리터럴이 아닌 것을 찾아라

### 주어진 항목

```javascript
(0, 12.34, "a", 0xff, ff, null, false, "hello", 4 + 5);
```

**정답: `ff`, `4+5`**

### 설명

리터럴은 코드에 직접 적은 값이다.

| 항목      | 구분        | 설명                                |
| --------- | ----------- | ----------------------------------- |
| `0`       | 리터럴      | 정수 값                             |
| `12.34`   | 리터럴      | 실수 값                             |
| `"a"`     | 리터럴      | 문자열 값                           |
| `0xff`    | 리터럴      | 16진수로 표현한 숫자 값             |
| `ff`      | 리터럴 아님 | 변수 이름으로 사용할 수 있는 식별자 |
| `null`    | 리터럴      | 값이 없음을 나타내는 값             |
| `false`   | 리터럴      | 논리 값                             |
| `"hello"` | 리터럴      | 문자열 값                           |
| `4+5`     | 리터럴 아님 | 두 숫자를 더하는 연산식             |

## 4. `3/2+"px"`의 연산 결과는 무엇인가?

**정답: ③ `"1.5px"`**

### 설명

- 자바스크립트에서 `3 / 2`의 결과는 `1.5`이다.
- 숫자와 문자열을 `+`로 연결하면 문자열이 된다.

```javascript
3 / 2 + "px";
// 결과: "1.5px"
```

## 5. 자바스크립트 언어의 구문이 아닌 것은?

**정답: ② `loop`**

### 설명

- **① `break`**: 반복문이나 `switch`문을 종료할 때 사용한다.
- **② `loop`**: 자바스크립트의 구문이나 예약어가 아니다.
- **③ `switch`**: 값에 따라 실행할 코드를 선택하는 조건문이다.
- **④ `continue`**: 현재 반복의 나머지 부분을 건너뛰고 다음 반복으로 넘어간다.

자바스크립트의 반복문에는 `for`, `while`, `do...while` 등이 있다.

## 6. `case`문으로 잘못 사용한 것은?

**교재에서 의도한 정답: ④ `case x>6 :`**

### 설명

교재에서는 `switch`의 값과 일치하는 값을 `case`에 적는 기본적인 사용법을 묻는 것으로 보인다.

- **① `case 3 :`**: 숫자 `3`과 비교한다.
- **② `case "s" :`**: 문자열 `"s"`와 비교한다.
- **③ `case 3+2 :`**: 계산 결과인 `5`와 비교한다.
- **④ `case x>6 :`**: 조건식의 결과인 `true` 또는 `false`와 비교하므로, 일반적인 숫자 값에 따른 분기와는 다르다.

### 주의

**실제 자바스크립트 문법에서는 ④도 유효하다.** 따라서 문법 오류를 묻는 문제로 해석하면 네 보기 중 잘못된 문법은 없다. `x`가 선언되어 있다면 다음처럼 사용할 수 있다.

```javascript
let x = 7;

switch (true) {
  case x > 6:
    document.write("x는 6보다 큽니다.");
    break;
}
```

## 7. 다음 문장의 실행 결과 `w`, `x`, `y`, `z`의 값은 무엇인가?

### (1) 주어진 코드

```javascript
let x = 1,
  y = 2,
  z = 3,
  w = 4;
y = x++;
z += x;
w = w > 3 ? w - 3 : 3 - w;
```

**정답: `w = 1`, `x = 2`, `y = 1`, `z = 5`**

### 설명

- `y = x++`: 기존 `x` 값인 `1`을 `y`에 저장하고, `x`를 `2`로 증가시킨다.
- `z += x`: `3 + 2`이므로 `z`는 `5`가 된다.
- `w > 3`은 참이므로 `w - 3`, 즉 `4 - 3`을 저장한다.

| 변수 | 최종 값 |
| ---- | ------- |
| `w`  | `1`     |
| `x`  | `2`     |
| `y`  | `1`     |
| `z`  | `5`     |

### (2) 주어진 코드

```javascript
let a = 1,
  b = 2,
  c = 3,
  d = 4;
let x = a > 1 || c != 3;
let y = a != b && c != d;
let z = b << c;
let w = a == 1;
```

**정답: `w = true`, `x = false`, `y = true`, `z = 16`**

### 설명

- `x`: `false || false`이므로 `false`이다.
- `y`: `true && true`이므로 `true`이다.
- `z`: `2`를 왼쪽으로 `3`비트 이동하면 `16`이 된다.
- `w`: `a`가 `1`이므로 `true`이다.

| 변수 | 최종 값 |
| ---- | ------- |
| `w`  | `true`  |
| `x`  | `false` |
| `y`  | `true`  |
| `z`  | `16`    |

## 8. 다음 문장의 실행 결과 `s`, `t`의 값은 무엇인가?

### (1) 주어진 코드

```javascript
let s = 1 + 2 + "hello" + 3;
let t = 1 + "hello" + 2 + 3;
```

**정답: `s = "3hello3"`, `t = "1hello23"`**

### 설명

`+`는 왼쪽부터 계산하며, 문자열과 연결된 이후에는 문자열 연결이 이루어진다.

```javascript
// s의 계산 과정
1 + 2; // 3
3 + "hello"; // "3hello"
"3hello" + 3; // "3hello3"

// t의 계산 과정
1 + "hello"; // "1hello"
"1hello" + 2; // "1hello2"
"1hello2" + 3; // "1hello23"
```

### (2) 주어진 코드

```javascript
let s = "hello" > "javascript";
let t = "아버지" > "어머니";
```

**정답: `s = false`, `t = false`**

### 설명

- 문자열은 앞쪽 문자부터 UTF-16 코드 값의 순서로 비교한다.
- `"hello"`의 첫 글자 `h`는 `"javascript"`의 첫 글자 `j`보다 앞에 있으므로 `false`이다.
- `"아버지"`의 첫 글자 `아`는 `"어머니"`의 첫 글자 `어`보다 앞에 있으므로 `false`이다.

## 9. 다음 코드에서 지역변수와 블록 변수 그리고 전역변수를 찾아 나열하라

### (1) 주어진 코드

```javascript
let x;

function f() {
  let y = x + 5;
  z = y + 5;
  return z;
}
```

### 정답

| 구분                  | 변수     |
| --------------------- | -------- |
| 지역변수              | `y`      |
| 별도의 내부 블록 변수 | 없음     |
| 전역변수              | `x`, `z` |

### 설명

- `x`는 함수 밖에서 선언되었으므로 전역변수이다.
- `y`는 함수 안에서 선언되었으므로 함수 내부에서만 사용할 수 있는 지역변수이다.
- `z`는 선언 없이 값을 대입했다. 일반적인 비엄격 모드에서는 함수가 실행될 때 전역변수가 생성된다.
- `let`으로 선언한 `y`는 정확히는 함수 본문 블록을 범위로 갖는다. 여기서는 교재의 구분에 따라 지역변수로 분류했다.

### (2) 주어진 코드

```javascript
sum = 0;

function f() {
  let x = 1;
  for (let n = 0; n < 5; n++) sum += x;
}
```

### 정답

| 구분      | 변수  |
| --------- | ----- |
| 지역변수  | `x`   |
| 블록 변수 | `n`   |
| 전역변수  | `sum` |

### 설명

- `x`는 함수 안에서 선언되어 함수 내부에서 사용한다.
- `n`은 `for`문에서 `let`으로 선언되어 해당 반복문 안에서만 사용할 수 있다.
- `sum`은 함수 밖에서 선언 없이 값을 대입한 변수로, 비엄격 모드에서는 전역변수가 된다.

## 10. 다음 코드의 실행 결과 출력되는 내용은 무엇인가?

### (1) 주어진 코드

```javascript
let sum = 0;

function acc() {
  let sum = 0;
  for (let i = 0; i < 10; i++) sum += i;
}

acc();
document.write("합 = " + sum);
```

**정답: `합 = 0`**

### 설명

- 함수 안의 `sum`과 함수 밖의 `sum`은 서로 다른 변수이다.
- 반복문은 함수 안의 지역변수 `sum`에 `0`부터 `9`까지 더한다.
- 함수 밖의 `sum`은 변하지 않으므로 `0`이 출력된다.

### 출력 결과

```text
합 = 0
```

### (2) 주어진 코드

```javascript
var sum = 0;

function acc() {
  var sum = 0;
  for (let i = 0; i < 10; i++) this.sum += i;
}

acc();
document.write("합 = " + sum);
```

**정답: `합 = 45`**

### 설명

- 일반적인 브라우저의 비엄격 모드 `<script>` 실행을 기준으로 한다.
- 함수 밖에서 `var`로 선언한 `sum`은 `window` 객체의 프로퍼티가 된다.
- `acc()`처럼 호출하면 함수 안의 `this`는 `window`를 가리킨다.
- 따라서 `this.sum`은 지역변수가 아닌 전역변수 `sum`을 가리킨다.
- `0`부터 `9`까지 더하면 `45`가 된다.

### 출력 결과

```text
합 = 45
```

**정답: ② `53/10 = 5`**

### 설명

자바스크립트에서 `/`는 나눗셈 결과의 소수 부분을 버리지 않는다.

| ④ `53 * 10 = 530` | `530`          | 맞음 |

## 12. 다음 웹 페이지가 출력되는 모양을 그려라

### (1) 주어진 HTML 코드

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>1</title>
  </head>
  <body>
    <script>
      document.write("Welcome");
    </script>
  </body>
</html>
```

**정답: 웹 페이지 본문에 `Welcome`이 출력된다.**

### 출력 결과

```text
Welcome
```

### 설명

- `document.write("Welcome")`이 바로 실행된다.
- 브라우저 탭 제목은 `1`이다.

### (2) 주어진 HTML 코드

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>2</title>
  </head>
  <body>
    <script>
      function print() {
        document.write("Welcome<br>");
      }
    </script>
  </body>
</html>
```

**정답: 본문에 아무것도 출력되지 않는다.**

### 설명

- `print()` 함수를 정의했지만 호출하지 않았다.
- 함수 안의 코드는 함수를 호출해야 실행된다.
- 브라우저 탭 제목은 `2`이고, 본문은 빈 화면이다.

### 실행하려면

```javascript
print();
```

## 13. 다음과 같이 변수 `a`, `b`가 선언되어 있을 때, 각 계산 후 `a`, `b` 값은 무엇인가?

### 주어진 코드

```javascript
let a = 20,
  b = 2;
```

### 정답

각 항목은 **처음 값인 `a = 20`, `b = 2`에서 독립적으로 계산**한다.

| 식                              | a    | b      |
| ------------------------------- | ---- | ------ |
| (1) `a += b;`                   | `22` | `2`    |
| (2) `a = a << b;`               | `80` | `2`    |
| (3) `a = (a > 100) ? a : b;`    | `2`  | `2`    |
| (4) `b = (a > 10) && (a < 30);` | `20` | `true` |

### 설명

- **(1)** `a = a + b`와 같으므로 `20 + 2 = 22`이다.
- **(2)** `20`을 왼쪽으로 `2`비트 이동하면 `80`이 된다.
- **(3)** `20 > 100`은 거짓이므로 `b`의 값 `2`를 `a`에 저장한다.
- **(4)** `20 > 10`과 `20 < 30`이 모두 참이므로 `b`는 `true`가 된다.

## 14. 다음과 같이 변수 `a`, `b`가 선언되어 있을 때, 각 계산 후 `a`, `b` 값은 무엇인가?

### 주어진 코드

```javascript
let a = "123",
  b = "45";
```

### 정답

각 항목은 **처음 값인 `a = "123"`, `b = "45"`에서 독립적으로 계산**한다. 따옴표가 있는 값은 문자열이고, 따옴표가 없는 값은 숫자이다.

| 식                                   | a           | b         |
| ------------------------------------ | ----------- | --------- |
| (1) `a += b;`                        | `"12345"`   | `"45"`    |
| (2) `a = parseInt(a) + parseInt(b);` | `168`       | `"45"`    |
| (3) `a = 10 + a + b;`                | `"1012345"` | `"45"`    |
| (4) `b = 10 + parseInt(a) + "ab";`   | `"123"`     | `"133ab"` |

### 설명

#### (1) `a += b;`

문자열끼리 `+` 연산을 하면 두 문자열을 연결한다.

```javascript
"123" + "45";
// 결과: "12345"
```

#### (2) `a = parseInt(a) + parseInt(b);`

`parseInt()`로 문자열을 정수로 바꾼 후 더한다.

```javascript
123 + 45;
// 결과: 168
```

#### (3) `a = 10 + a + b;`

왼쪽부터 계산하며, 숫자와 문자열을 연결하면 문자열이 된다.

```javascript
10 + "123"; // "10123"
"10123" + "45"; // "1012345"
```

#### (4) `b = 10 + parseInt(a) + "ab";`

먼저 숫자끼리 더하고, 그 결과를 문자열 `"ab"`와 연결한다.

```javascript
10 + 123; // 133
133 + "ab"; // "133ab"
```
