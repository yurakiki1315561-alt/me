3장 HTML5 문서 구조화와 폼 — 이론문제
1. HTML5 표준에 명시된 것으로 HTML 페이지에 반드시 있어야 하는 것이 아닌 것은?
정답: ② <img>

<!DOCTYPE html>, <html>, <head>, <body>는 HTML5 문서의 기본 골격이므로 반드시 포함되어야 한다. <img>는 이미지가 필요할 때만 선택적으로 사용하는 태그이다.

2. 검색 엔진이 좋아하는 태그가 아닌 것은?
정답: ① <div>

<summary>, <section>, <mark>는 내용의 의미를 알려주는 시맨틱(semantic) 태그이다. 반면 <div>는 단순히 영역을 묶기만 할 뿐 아무런 의미를 담지 않아서, 검색 엔진이 그 안의 내용이 무엇인지 판단할 수 없다.

3. HTML5에서 문서 구조화와 관련이 먼 태그는?
정답: ② <span>

<section>(내용 구획), <nav>(내비게이션), <figure>(그림·도표)는 모두 문서의 구조를 나타내는 태그이다. <span>은 텍스트 일부에 스타일을 적용하기 위한 인라인 태그일 뿐, 구조와는 관계가 없다.

4. HTML5에서 문서의 구조화를 강력히 추진하는 이유는?
정답: ① 웹 페이지 내 가치 있는 정보의 탐색이 원활하도록 하기 위해

구조화의 목적은 보기 좋은 화면을 만드는 것이 아니라, 기계(검색 엔진·프로그램)가 페이지의 어느 부분이 제목이고 본문이고 저작권 정보인지 스스로 파악하게 만드는 데 있다. 화면 모양을 꾸미는 일은 CSS의 역할이다.

5. 개발자가 시맨틱 웹에 맞추어 웹 페이지를 작성해야 하는 이유는?
정답: ③ 검색 엔진이 좋아하는 웹 페이지로 만들기 위해

시맨틱 태그를 사용하면 검색 엔진이 내용의 의미를 정확히 해석하여 검색 결과 상위에 노출될 가능성이 높아진다. 사용자는 어차피 브라우저 화면으로 내용을 보기 때문에, 의미 전달의 대상은 사람이 아니라 기계이다.

6. 검색 엔진이 저작권 정보를 웹 페이지 내에서 검색할 때 어떤 태그를 검색하면 좋을까?
정답: ② <footer>

<footer>는 문서나 섹션의 맨 아래에 들어가는 저작권, 작성자, 연락처 등의 정보를 담는 태그이다. <copyright>라는 태그는 HTML에 존재하지 않는다.

7. 웹 문서의 목차 정보를 두기에 바람직한 태그는?
정답: ④ <nav>

<nav>는 다른 페이지나 문서 내 위치로 이동하는 링크들을 모아두는 태그로, 목차나 메뉴를 표현하기에 적합하다.

8. 빈칸에 알맞은 <form> 태그의 속성을 넣으시오
<form> 태그의 ( action ) 속성은 웹 서버 응용프로그램 이름을 지정하며, ( method )는 폼 데이터를 웹 서버로 전송할 때 데이터를 전송하는 방식을 결정한다. 이 방법에는 ( get )와 ( post )가 있다. 그리고 ( target ) 속성에는 웹 서버로부터 받은 결과를 출력할 윈도우 이름을 지정한다.

속성	역할
action	폼 데이터를 처리할 서버 프로그램의 주소
method	전송 방식 지정 (get / post)
get	데이터를 URL 뒤에 붙여 전송, 길이 제한 있고 노출됨
post	데이터를 본문에 담아 전송, 길이 제한 없고 노출되지 않음
target	서버의 응답 결과를 출력할 윈도우(또는 프레임) 이름
<form action="save.jsp" method="post" target="_blank"></form>
9. 다음 물음에 대해 적절한 폼 요소를 작성하라
(1) −5에서 5까지 0.5 단위로 숫자 입력이 가능한 폼 요소
<input type="number" min="-5" max="5" step="0.5" />
min과 max로 입력 범위를, step으로 증감 단위를 지정한다.

(2) 달력에 2017년 5월 달로 초기화하고 몇 월 달인지 입력받는 폼 요소
<input type="month" value="2017-05" />
type="month"는 연도와 월만 선택하며, 값의 형식은 YYYY-MM이다.

(3) "자바스크립트" 문자열과 함께 출력되는 체크박스
<input type="checkbox" id="js" name="lang" value="javascript" />
<label for="js">자바스크립트</label>
<label>의 for를 입력 요소의 id와 일치시키면 글자를 눌러도 체크된다.

(4) "오후 7시" 문자열과 함께 출력되는 라디오버튼
<input type="radio" id="pm7" name="time" value="19" />
<label for="pm7">오후 7시</label>
라디오버튼은 같은 name을 가진 것끼리 한 그룹이 되어 하나만 선택된다.

10. 버튼에 대한 설명으로 틀린 것은?
정답: ④ <button type="button"> 버튼은 <form> 없이 사용되어야 한다.

<button type="button">은 <form> 안에서도 밖에서도 모두 사용할 수 있다. type="button"은 아무 기본 동작이 없는 버튼이라는 뜻일 뿐이며, 폼의 존재 여부와는 무관하다.

보기	설명	판정
①	type="button"은 자체 기능이 없고 자바스크립트를 연결해서 사용	맞음
②	type="reset"은 폼의 입력 내용을 초기 상태로 되돌림	맞음
③	type="submit"은 폼 데이터를 action의 주소로 전송	맞음
④	<form> 없이 사용되어야 한다	틀림
